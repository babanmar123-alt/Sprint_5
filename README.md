# Sprint_5 — UI-тестирование сервиса Stellar Burgers

Автотесты для сервиса Stellar Burgers (космический фастфуд) на Selenium.

---

## Описание проекта

Проект содержит автотесты для проверки функциональности учебного приложения **Stellar Burgers**. 

**Сайт:** https://stellarburgers.nomoreparties.site/

---

## Что проверяется

В проекте написаны тесты для следующих сценариев:

### 1. Регистрация
- Успешная регистрация с валидными данными
- Ошибка при вводе некорректного пароля (менее 6 символов)

### 2. Вход в аккаунт (4 способа)
- Вход по кнопке «Войти в аккаунт» на главной странице
- Вход через кнопку «Личный кабинет»
- Вход через кнопку в форме регистрации
- Вход через кнопку в форме восстановления пароля

### 3. Личный кабинет
- Переход в личный кабинет по клику на кнопку
- Переход из личного кабинета в конструктор по клику на «Конструктор»
- Переход из личного кабинета в конструктор по клику на логотип Stellar Burgers
- Выход из аккаунта по кнопке «Выйти»

### 4. Конструктор
- Переход к разделу «Булки»
- Переход к разделу «Соусы»
- Переход к разделу «Начинки»

---

## 5. Технологии

- **Python** — язык программирования
- **Selenium** — библиотека для автоматизации браузера
- **pytest** — фреймворк для тестирования
- **webdriver-manager** — автоматическое управление драйверами браузера
- **Chrome / Firefox** — браузеры для запуска тестов

Особенности
Все тесты автономны — каждый тест открывает браузер, выполняет свою задачу и закрывает браузер.

Для каждого теста используется команда driver.quit().

Тесты используют уникальные email для регистрации, чтобы избежать конфликтов.

Пароль для тестов генерируется автоматически (6 символов — для успешной регистрации, 5 символов — для проверки ошибки).
